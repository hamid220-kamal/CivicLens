# 90-Second Demo Script

1. "I am a citizen. I see a civic problem. I don't know which department handles it."
2. Upload a real image and allow location access.
3. Submit the report.
4. Show AI classification, severity and department recommendation with RAG source evidence.
5. Submit a second real report for the same/nearby problem.
6. Show that CivicLens recognizes a possible existing incident instead of blindly creating another isolated ticket.
7. Open the authority dashboard.
8. End with: "CivicLens turns scattered citizen observations into structured civic incidents that can be prioritized and routed with evidence."
